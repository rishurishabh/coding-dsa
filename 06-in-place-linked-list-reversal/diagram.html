Reversal: one flip, repeated

Save `next` before you overwrite it, point `curr.next` backward, advance both pointers. Every variant is that one relink — bounded to a whole list, a range, or a group. Code lives in 06-in-place-linked-list-reversal/*.js.

Iterative three-pointer relink

Save next before overwriting curr.next. prev ends on the old tail — the new head.

02-reverse-recursive.js

Recursive relink

By the time any node relinks itself, everything after it is already reversed — the recursive trust.

03-reverse-sublist.js

Bound + splice back

Head-insertion moves each node in the range to the front of the range — one prev pointer is all it takes.

04-reverse-k-group.js

Bounded reversal, repeated

Confirming k full nodes exist before reversing is what lets a short trailing group stay untouched.

05-reverse-alternating-k-group.js

Reverse, skip, repeat

Same relink as variant 4, but a skip phase passes through untouched — recursion tracks the toggle naturally.

Knapsack: include it, or don't

Every cell in the DP array is the better of two choices: skip this item (keep what capacity c already had), or take it (capacity c minus its weight, plus its value). Code lives in 19-01-knapsack/*.js.

exclude — unchanged
include — from a smaller capacity

The core move

dp[c] = better of exclude vs include

Six variants

One recurrence, read as a max, a boolean, or a count

01-knapsack-max-value.js

Include-or-exclude, maximize value

Every (item, capacity) pair asks one question: does including this item beat excluding it?

02-subset-sum-exists.js

Same recurrence, boolean reachability

No value to maximize — just true/false, propagated the same way variant 1 propagates a max.

03-equal-subset-partition.js

Reduce to variant 2

The problem doesn't look like subset sum — until "equal halves" is rewritten as "one half = total/2".

04-count-subsets-with-sum.js

Same recurrence, counting

Existence and counting share the same DP shape — only the update operator changes.

05-target-sum-assignment.js

Reduce to variant 4 via algebra

Two linear equations collapse "how many sign assignments" into "count subsets summing to P".

06-minimum-subset-sum-difference.js

Read variant 2's table differently

Same reachability table as variant 2 — the question changes from "is X reachable" to "what's closest to X".

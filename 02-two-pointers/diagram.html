Two Pointers: five ways to move two indices

Sliding window is two pointers moving the same direction with a gap between them. This module is everything else: pointers converging from opposite ends, walking independently across two sequences, or partitioning one array in place. The code lives in 02-two-pointers/*.js.

L / left / low pointer
R / right / high pointer (or the other sequence)
result — the answer being reported

The classic case

Opposite ends, converging inward

Eleven variants

What differs is the rule, the direction, or how many sequences

01-opposite-converging.js

Opposite ends, comparison-driven

Sum too big → R steps in; too small → L steps out. Sorted order guarantees each step rules out a whole row or column of pairs.

02-move-the-smaller.js

Greedy: move the shorter wall

Area is capped by the shorter wall. Moving the taller one can't help — only the shorter wall (rose) has any chance of a bigger area.

03-running-max-both-sides.js

Running max on both sides

Whichever side has the smaller running max is already fully resolved — that pointer is safe to settle and advance.

04-read-write-pointers.js

Same direction: read / write

write only advances (and copies) when read finds something that belongs — compacts in place, one pass, no extra array.

05-three-pointers-partition.js

Three-pointer in-place partition

low/mid/high maintain three growing regions; mid only advances once its own cell is classified — one pass sorts all three buckets.

06-fix-one-two-pointer-rest.js

Fix one, two-pointer the rest

Each anchor turns "find a pair" (variant 1) into "find a triplet" — same converging search, run once per anchor.

07-two-array-merge.js

Independent pointers, two sequences

Each pointer walks its own array. Whichever current value is smaller is always safe to emit next — O(n+m) total.

08-palindrome-check.js

Symmetry check, no target

No target to search for — only "do the two ends match". Mismatch means fail (or branch once, for the one-deletion variant).

09-in-place-reverse-swap.js

Unconditional swap, every step

The simplest two-pointer shape: every step is the same unconditional swap. Reverse, or rotate via three reversals.

10-fixed-gap.js

Fixed-gap pointers

The gap is fixed before the walk starts, not data-driven. When lead hits the end, trail is provably n nodes behind.

11-pivot-partition.js

Pivot partition (Hoare scheme)

The boundary is whatever the pivot's value is. Each swap moves one element to its side, converging on the pivot's final index in O(n).

The core move

Four recipes, one bit position, one mask

CHECK

(n >> i) & 1

slide bit i down, read the last column

n=1010, i=1

→ true (set)

SET

n | (1<<i)

OR forces that bit to 1, leaves rest alone

n=1010, i=2

→ 1110 (14)

CLEAR

n & ~(1<<i)

AND forces that bit to 0, leaves rest alone

n=1110, i=2

→ 1010 (10)

TOGGLE

n ^ (1<<i)

XOR flips that bit, leaves rest alone

n=1010, i=2

→ 1110 (14)

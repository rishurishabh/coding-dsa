Five variants

General-purpose baseline — works for min/max/gcd too, not just sum.

02-fenwick-tree-range-sum.js

Fenwick tree, point update

Same workload as variant 1, sum-only — smaller structure, no recursion.

03-segment-tree-lazy-propagation.js

Segment tree + lazy tags

A fully-covered node updates itself and defers its children until they're actually visited.

04-fenwick-range-update-point-query.js

Fenwick over a difference array

A range update becomes two point updates on the diff array — no lazy tags needed.

05-count-smaller-after-self.js

Fenwick tree for order statistics

Same walk as every other variant, storing frequencies by compressed rank instead of sums.

One locally-optimal choice per step, made irreversibly — no table of subproblem answers like DP builds. The hard part is proving the local rule is safe. Code lives in 24-greedy/*.js.

The core move

Five variants

Same "commit and move on," five different safety proofs

01-non-overlapping-intervals.js

Sort by end, exchange argument

Swapping any kept interval for the earliest ender never costs more room downstream.

02-jump-game.js

Farthest-reach feasibility

One running number replaces every earlier choice — if it falls behind i, nothing saves it.

03-jump-game-ii.js

Boundary expansion (BFS levels)

Same idea as variant 2, plus a second boundary — one level of BFS per committed jump.

04-gas-station.js

Running deficit, reset point

A failed stretch disqualifies every start inside it at once, not just the one that broke it.

05-candy.js

Two-pass, combine via max

Neither one-directional pass satisfies both neighbors — the max of both passes does.

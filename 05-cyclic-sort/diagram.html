Cyclic Sort: everyone has one correct seat

Every value knows its own home index without comparing to anything else. Swap it there directly; whatever's left in the wrong seat afterward tells you what's missing or duplicated. Code lives in 05-cyclic-sort/*.js.

The core move

Swap into place, don't compare

Six variants

One swap loop, five ways to read the leftovers

01-basic-placement.js

The placement loop itself

Each swap seats one value permanently. No comparisons — value v always goes straight to index v−1.

02-find-missing-number.js

First mismatch

After placement, the one index not holding its own value points straight at the missing number.

03-find-all-missing.js

Every mismatch, missing side

A duplicate squatting on someone else's home shows up as a mismatch at the missing value's OWN index too.

04-find-duplicates.js

Every mismatch, duplicate side

Same leftover cells as variant 3 — read as "this value has no home left" instead of "this index has no value".

05-corrupt-pair.js

One mismatch, two answers

Value AND index of the same cell each answer a different question — no second pass needed.

06-first-missing-positive.js

Placement with a range guard

The swap condition adds a range check — values that could never be the answer are skipped, not placed.

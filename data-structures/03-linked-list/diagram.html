Linked list: a chain of pointers, not a block

Each node only points to what comes next — inserting at the head is one pointer swap, reaching any other position means walking node by node. Code lives in data-structures/03-linked-list/*.js.

01-singly-linked-list.js

02-doubly-linked-list.js

Core CRUD, both directions

03-merge-two-sorted-lists.js

Merge by re-linking

A dummy head absorbs the "is this the first node?" case — no new nodes ever allocated.

04-lru-cache.js

Doubly linked list + hash map

The map gives O(1) lookup by key; the doubly linked list gives O(1) reorder and eviction.

05-add-two-numbers.js

Digit-by-digit with carry

Least-significant digit first — both lists walked in lockstep, a carry can add one final digit.

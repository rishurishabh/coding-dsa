XOR: pairs cancel, survivors don't

`a ^ a = 0`. XOR every element in a sequence together and every duplicate pair vanishes — whatever's left over is the answer. Code lives in 18-bitwise-xor/*.js.

01-single-number-cancellation.js

XOR cancellation

One running XOR, one pass — no hashset needed to track what's been seen.

02-single-number-two-uniques.js

Partition by a differing bit

The lowest set bit of (a^b) is where a and b differ — split there, then variant 1 works on each half.

03-single-number-triple-appearing.js

Bit-count state machine

Plain XOR assumes pairs. Three copies need a real counter, tracked per bit position instead of per value.

04-missing-number-xor.js

XOR indices against values

Same cancellation, but the "duplicate" being matched is an index from the expected range, not a repeated value.

05-complement-flip-bits.js

Mask + XOR to flip

~num flips leading zeros too — a purpose-built mask confines the flip to bits that actually matter.

06-counting-bits-kernighan.js

n & (n-1) clears the lowest bit

n-1 flips everything below the lowest set bit; ANDing with n erases just that one bit, cleanly.

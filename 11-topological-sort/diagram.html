Topological Sort: release what has no prerequisites left

A node with in-degree 0 owes nothing to anyone — it's always safe to output. Outputting it frees its neighbors of one dependency each, which may make them safe too. Code lives in 11-topological-sort/*.js.

Six variants

Two base algorithms, four ways to steer them

01-kahns-bfs.js

Kahn's algorithm

Output, decrement, check for new zeros — the plain, no-frills version every other variant modifies.

02-dfs-postorder.js

DFS postorder, reversed

A node finishes only after everything it points to has already finished — so finish order is backwards.

03-course-schedule-levels.js

Kahn's, drained level by level

Everything drained in one queue-size snapshot has no dependency on anything else in that same snapshot.

04-lexicographically-smallest-order.js

Kahn's + min-heap

Same three choices every time — the heap guarantees the smallest one is taken first, deterministically.

05-all-topological-orders.js

Kahn's, backtracked

Every simultaneously-ready node is a real fork — explore each choice fully, then backtrack and try the next.

06-alien-dictionary.js

Build the graph, then sort it

The graph isn't given — every adjacent word pair contributes at most one edge, from its first differing letter.
